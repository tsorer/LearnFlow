Warum diese Trennung

Die Regellogik kennt das SDK nicht. Dadurch ist sie isoliert testbar — 27 Unit-Tests, ohne Netz, ohne API-Kosten — und später auch ohne Agent im CI nutzbar.

Guardrails

max_turns, max_budget_usd, permission_mode, dazu tools und allowed_tools. Genau diese fünf haben wir einzeln gegen die Wand gefahren.

Warum es hängt

Die Permission-Prüfung ergibt „ask". Im SDK ersetzt der can_use_tool-Callback den interaktiven Prompt — den haben wir nicht gesetzt, also kann niemand zusagen. Der Aufruf kommt nie zustande, und das Skript läuft ohne Fehler ins Leere.

Was es trotzdem kostet

Bezahlt ist zu diesem Zeitpunkt alles: Datei gelesen, Tool-Schema geladen, der 12'077-Zeichen-Block aufgebaut. $0.1885 für null Ergebnis. Eine fehlende Freigabe fällt erst am Ende der Werkzeugkette auf — nicht davor.

Das gute Verhalten

Der Agent rät den Dateinamen viermal, gibt dann auf und fragt — er erfindet keinen Inhalt für ADR-009. Genau das Verhalten, das wir für LearnFlow brauchen.

Der Nebeneffekt

ToolSearch verschwand aus dem Stream: Mit kleinem Werkzeugkasten kennt das Modell die MCP-Tools sofort und ruft sie direkt auf, statt erst ihr Schema zu laden. Weniger Tools heisst auch weniger Umwege.

Was wir mitnehmen

Vier Dinge, die im Handout so nicht standen

Verfügbarkeit ≠ Genehmigung

allowed_tools ist die Freigabe, tools der Werkzeugkasten. Lauf 2 zeigt die eine Hälfte — ohne Freigabe stirbt die Kette am letzten Glied; Lauf 7 die andere — ohne tools hat der Agent Bash und Write im Kontext, nur eben unbestätigt.

Guardrails sind Exceptions

Budget- und Turn-Limit beenden den Prozess mit Stacktrace. Wer sie produktiv nutzt, muss sie abfangen und den Teilstand sichern.

MCP-Tools kosten einen Umweg

Bei vollem Werkzeugkasten lädt die Engine das Schema erst per ToolSearch — ein zusätzlicher Turn, bevor das eigene Tool überhaupt läuft.

Die Beschreibung ist der Vertrag

Der Agent hat die Richtung von celsius_to_f aus der Beschreibung gelesen und die Lücke offengelegt, statt sie zu überspielen. Schlechte Beschreibungen erzeugen genau hier stille Fehler.
