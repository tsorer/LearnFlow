Arbeitsweise

Wir haben den Code nicht geschrieben. Wir haben entschieden.

Claude Code erzeugt die Implementierung. Damit das trägt, muss jeder Entscheid schriftlich, auffindbar und maschinell prüfbar sein — sonst wird er in der nächsten Sitzung neu erfunden.

Steht so in unserer Definition of Done „Code wird KI-gestützt mit Claude Code erzeugt; die Teammitglieder sind primär Reviewer und Verifizierer. Daraus folgt: das menschliche Review und die automatisierten Gates sind die Qualitätssicherung, nicht das Schreiben des Codes."

Architekturentscheide

Ein Entscheid, der nur im Code steht, wird jede Woche neu diskutiert

Zehn ADRs, geschrieben bevor die erste Zeile Produktionscode entstand. Nicht als Pflichtübung aus dem Unterricht — sondern weil ein ADR die Form ist, in der auch eine Maschine eine Vorgabe entgegennimmt.

ADR-008 trägt im Kopf sechs Nachträge. Jeder davon ist eine Erkenntnis aus einem konkreten Ticket, die zurück in den Entscheid geflossen ist. ADRs sind bei uns kein Archiv, sondern Arbeitsmaterial.

Rhythmus

Bauen. Absichern. Messen.

Neun Sprints als GitHub-Meilensteine. Kein Scrum-Theater — keine Dailys, keine Velocity-Rechnung, keine Retro-Formate. Geblieben ist, was bei einem nebenberuflichen Team trägt: feste Zeitbox, Milestone am Ticket, ein Board, klare Reihenfolge.

Die Reihenfolge ist kein Zufall: erst funktionsfähig, dann fail-closed, dann messbar. Reliability vor Feature-Breite — so steht es in den Quality Attributes.

Umsetzung

Der Plan ist das Arbeitsprodukt. Der Code fällt danach an.

„Erstelle einen Umsetzungsplan für Issue #…" — so beginnen 18 der 40 dokumentierten Arbeitsverläufe. Keine Zeile Code, bevor nicht jeder offene Punkt entschieden ist.

Der Satz, der den Prozess trägt „Erstelle einen Plan, wie das Issue umgesetzt werden kann. Stelle mir vor der Umsetzung Fragen, bis alle Unklarheiten geklärt sind."
Nicht „schreib mir Code", sondern „frag mich, bis du es verstanden hast". Zweimal deckte allein die Bestandsaufnahme einen Widerspruch in unseren eigenen Dokumenten auf, den vorher niemand gesucht hatte.

Review

Vier Schichten. Keine trägt allein.

Wenn die KI den Code schreibt, ist das klassische Vier-Augen-Review nicht mehr die stärkste Kontrolle — niemand hat den Code Zeile für Zeile im Kopf. Wir haben die Prüfung deshalb gestaffelt.

Die KI findet die Inkonsistenz. Nur der Mensch weiss, welche der beiden Versionen die gemeinte war.
