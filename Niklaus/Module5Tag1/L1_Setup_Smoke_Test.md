# L1 · Setup & Smoke-Test
**Zeit:** 13:00 – 13:30  
**Thema:** Sauber starten und sicherstellen dass alles läuft

---

Bevor ihr loslegt — stellt sicher dass euer Setup funktioniert. Das spart später Frust.

## Checkliste

- [ ] Werkzeuge/Environment bereit? (Python: conda/venv · Java/.NET/Node: SDK im PATH)
- [ ] Im Projekt-Repo (`cd projekt` — wo eure `CLAUDE.md` liegt)?
- [ ] `git status` sauber / aktueller Stand gepullt?
- [ ] `claude` gestartet — zeigt es das richtige Projekt?
- [ ] Smoke-Test: «Was ist unser Tech-Stack?» — kennt Claude eure CLAUDE.md?

> **Warnung:** Wenn Claude bei «Was ist unser Tech-Stack?» nichts Konkretes sagt — ihr seid wahrscheinlich nicht im richtigen Ordner oder die CLAUDE.md fehlt. Erst das lösen, dann weiter.
