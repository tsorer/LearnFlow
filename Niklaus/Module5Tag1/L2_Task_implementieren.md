# L2 · Ersten Task implementieren
**Zeit:** 13:30 – 14:30  
**Thema:** Einen echten Task aus dem Sprint-Backlog bauen

---

Nehmt EINEN Task aus eurem Sprint-1-Backlog. Beginnt mit etwas Überschaubarem (2–3 Story Points) — nicht dem schwersten.

---

## Schritt 1 · Task wählen und als Spec formulieren (15 Min)

Erinnert euch an **Karpathy Layer 1:** erst Spec, dann Code. Lasst Claude euch helfen die Aufgabe zu schärfen:

```
> Wir wollen folgenden Task implementieren: [TASK-ID +
  BESCHREIBUNG aus dem Backlog].
  Akzeptanzkriterien: [AUS MODUL 2].

  Bevor du Code schreibst: stelle mir Rückfragen wo
  die Anforderung unklar ist. Schlage dann eine kurze
  Spec vor (Inputs, Outputs, Edge Cases).
```

**Reflexionsfragen:**
- Welcher Task?
- Welche Rückfragen hat Claude gestellt?

---

## Schritt 2 · Implementieren lassen (45 Min)

Wenn die Spec klar ist — lasst Claude implementieren. Arbeitet iterativ, prüft jeden Schritt:

```
> Gut, die Spec passt. Implementiere den Task jetzt
  Schritt für Schritt. Halte dich an unsere CLAUDE.md.
```

**Tipps:**
- Bestätigt jede Änderung einzeln mit «Yes» — beobachtet was Claude macht
- Versteht ihr was Claude schreibt? Wenn nicht — fragt: «erklär mir diese Funktion»
- Etwas nicht wie gewünscht? Nutzt «Tab» (amend) oder sagt klar was anders soll
- Tandem-Tipp: schwierige Design-Frage? Wechselt in den Chat (claude.ai) zum Durchdenken

**Reflexionsfrage:** Wo musstet ihr Claude korrigieren oder nachsteuern?
