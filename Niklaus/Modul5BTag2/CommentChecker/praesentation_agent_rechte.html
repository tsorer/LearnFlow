Zwei Agenten, drei Schranken

Wie Rollen, Rechte und Kosten in einem Pre-Commit-Agent zusammenhängen — und was drei scharfe Läufe darüber gelehrt haben.

Haupt-Agent · Sonnet Subagent · Haiku 2 Tools 3 Min
02Das Konstrukt

Vier Ebenen, jede enger als die darüber

Session — gilt für alles darin, Subagenten eingeschlossen
skills setting_sources strict_mcp_config max_budget_usd 0.30
Haupt-Agent — Sonnet · urteilt
staged_comments Agent Read Bash Write
Subagent — Haiku · übersetzt
language_signals staged_comments Agent Bash

Der Subagent sieht den Staging-Bereich gar nicht. Er bearbeitet nur den Text, den der Haupt-Agent ihm im Auftrag übergibt.

03Aufgabenverteilung

Jede Rolle bekommt, was nur sie kann

WerAufgabeweil
PythonUmlaute, Stoppwörter, transliterierte Formen findendeterministisch, sofort, gratis
ToolsFakten liefern — Staging lesen, Signale rechnenentscheiden nichts, haben keine Meinung
SonnetZweifelsfälle beurteilen, Bericht schreibenbraucht Urteil, kommt selten vor
Haikuenglische Fassungen schreiben und gegenprüfenRoutine, kommt oft vor

Dieselbe Trennlinie zweimal gezogen: erst Python ↔ Modell (was eindeutig ist ↔ was Urteil braucht), dann Sonnet ↔ Haiku (urteilen ↔ ausführen).

04Minimal Permission

Verfügbarkeit ist nicht Erlaubnis

Die Unterscheidung

  • tools — welche eingebauten Tools es überhaupt gibt
  • allowed_tools — welche davon ohne Rückfrage laufen dürfen
  • Steht ein Tool nicht in allowed_tools, ist es trotzdem im Kontext und kann angefordert werden
  • MCP-Tools sind über mcp_servers verfügbar — allowed_tools regelt nur die Rückfrage

Vier Quellen, einzeln zu schliessen

  • tools=["Agent"] — nur das Delegations-Tool
  • skills=[] — None heisst nicht „aus", sondern „alles"
  • setting_sources=[] — nichts von der Platte
  • strict_mcp_config=True — kein fremdes .mcp.json
Ehrlich bleiben

Der Haupt-Agent kann language_signals aufrufen, obwohl der Prompt ihm die Rolle nicht zuweist. Ihn wirklich fernzuhalten bräuchte zwei getrennte MCP-Server. Die Rollentrennung ist beim Subagenten durchgesetzt, beim Haupt-Agenten nur beschrieben.

05Kosten

Billig ist, was gar nicht erst läuft

kein Fund$0.00Modell wird nicht aufgerufen — der Normalfall
--alle$0.00nur die deterministische Hälfte, für die CI
Lauf mit Fehler$0.15989 Turns, 3 Delegationen, ohne Gegenprobe
Lauf repariert$0.06183 Turns, 1 Delegation, Gegenprobe gelaufen

Was spart

  • Kein Fund → kein Modell. Python hat schon geantwortet
  • Übersetzen läuft auf Haiku, nicht auf Sonnet
  • Das Modell sieht nur die Funde, nie das Repo — es kann gar nicht teuer suchen
  • Deckel auf beiden Ebenen: max_turns, max_budget_usd, sub.maxTurns

Was nicht spart

  • Die Einstufung sicher spart nicht den Aufruf — nur das Nachdenken darin
  • Ein falsch gesetztes Recht kostet doppelt: Wiederholungen plus Ergebnis ohne Prüfung
  • Bei fünf Kommentaren kostet die Delegation mehr, als Haiku spart. Sie lohnt bei vielen
06Learnings

Sechs Dinge, die ein Lauf gelehrt hat

01allowed_tools ist keine Verfügbarkeitsliste. Ein Agent mit allowed_tools=["Read","Grep"] rief trotzdem Agent auf. Der Filter heisst tools, der Skill-Schalter heisst skills.
02allowed_tools gilt für die ganze Session — Subagent inklusive. AgentDefinition.tools sagt nur, was er sieht. Fehlte die Erlaubnis, durfte der Übersetzer seine Gegenprobe nicht aufrufen und lieferte ungeprüft.
03None heisst nicht „aus". Bei skills und setting_sources bedeutet es „CLI-Standard", also alles. Ein vergessenes Feld sieht aus wie ein geschlossenes.
04agents= ohne Agent in tools ist tote Konfiguration. Sieht nach Fähigkeit aus, ist unerreichbar — und meldet nichts. Dieselbe stille Falle wie ein Vertipper im mcp__-Namen.
05Eine Zusicherung, die kein Test prüft, ist eine Absicht. „Das Modell bekommt kein Read und kein Bash" stand im Docstring, lange bevor es stimmte. Jetzt prüft es der Trockenlauf.
06Gezählte Pfade brechen still. parent.parent.parent nach einem Umzug: Git läuft im falschen Verzeichnis, meldet leeren Staging-Bereich statt Fehler — grün, ohne geprüft zu haben.

Ein roter Lauf hat mehr gezeigt als drei grüne. Und das Muster hinter allen sechs ist dasselbe: was nicht geprüft wird, gilt nicht — es steht nur da.
